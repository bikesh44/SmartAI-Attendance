# SAMS-FR Integration Checklist

## Frontend ↔ Backend

- [ ] API communication defined
- [ ] Authentication communication defined
- [ ] Request/response structure defined

## Backend ↔ Services

- [ ] Routes connected to services
- [ ] Business logic handled by services

## Services ↔ Database

- [ ] ER entities mapped to backend models
- [ ] Database relationships identified
- [ ] Database operations identified

## Backend ↔ Computer Vision

- [ ] Face registration result reaches backend
- [ ] Recognition result identifies student
- [ ] Recognition result reaches attendance processing

## Attendance

- [ ] Student identification available
- [ ] Attendance validation defined
- [ ] Attendance record can be stored

## Overall Architecture

Frontend
↓
Backend API
↓
Services
↓
Database
↓
Computer Vision
